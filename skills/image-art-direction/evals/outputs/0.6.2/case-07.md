# CASE 07

一张克制、极简的高端商业产品摄影：画面中只有一只简洁的透明玻璃香水瓶，直立放在无纹理的中性哑光平面上，瓶身是唯一的 Primary，黑色瓶盖作为同一产品的次级结构，不加入任何其他道具、人物或第二只瓶子。采用稳定的三分之四近距离产品构图，摄影机略低于瓶身中线、透视克制，完整呈现瓶身、瓶口与瓶盖，瓶子由平面和重力真实支撑，底部有贴合接触面的柔和阴影，不悬浮、不倾斜。瓶身轮廓简洁、无雕花和多余装饰，内部保持近乎无色，不让液体颜色夺走玻璃的视觉中心；不添加可读品牌、Logo 或装饰性标签。

透明玻璃必须显示真实的厚度与重量：侧壁和底部有可辨认的实体厚度，边缘出现连续但克制的亮带与暗边，玻璃内部对背景产生轻微、符合曲面和厚度的折射与放大变形，底部和瓶身与平面的接触处有自然的暗部，不能只用正面白色提亮来表示透明。背景使用无纹理的中性灰平滑渐变，在瓶身后方安排可控的明暗变化，让透明区域、折射轮廓、玻璃边缘和瓶内空间都能被看见；背景和反射只服务于瓶身识别，不形成戏剧化场景或抢夺视觉权重。黑色瓶盖是独立的不透明材质，以顶部和一侧的宽幅柔和反射、转折处的细微明暗变化及克制的边缘高光显出体积与平面，不糊成没有层次的纯黑，也不表现成透明或廉价高亮塑料。

灯光来自画外受控的产品摄影棚：一块大面积柔光箱位于左前上方，为瓶身和背景提供柔和的主要反射；左右侧后方各有窄而高的条形光，沿透明玻璃的侧缘和瓶盖轮廓描出连续、方向一致的高光；正面仅保留很弱的填充，避免玻璃变成均匀发白。曝光优先保留玻璃边缘、底部厚度、折射层次和黑色瓶盖的反射细节，允许背景渐变的局部高光受控下降，但不使用 HDR 抹平对比。画面干净、安静、精确，质感来自真实光学行为、材料分离和稳定构图，而不是堆叠装饰。

避免透明塑料感、没有厚度的空洞玻璃、玻璃与背景完全消失、黑色瓶盖死黑无层次、漂浮瓶子、无来源水珠、烟雾、雾气、金色装饰、珠宝、花朵、丝绸、豪华台座、镜面道具、额外瓶子、手部与人物、夸张光晕、镜头光斑、彩色戏剧灯光、过度情绪化场景、乱码文字、随机污渍、颗粒和人为曝光瑕疵；不把“高级”解释为奢华布景或重新设计瓶身结构。
