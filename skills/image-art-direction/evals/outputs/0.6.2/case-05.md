# CASE 05

请以提供的鼠标参考图为唯一产品依据，把它制作成正规的 Catalog / Cutout 白底产品图。锁定并原样保留参考图中实际可见的鼠标身份、外轮廓、几何结构、比例、朝向、部件数量与位置、按钮、滚轮、分件、接缝、固有颜色、表面材质，以及任何可见文字或 Logo；不要改按钮、改结构、增删部件、改变比例或重新设计产品，也不要补造参考图未展示且无法可靠判断的隐藏结构。沿用能够清楚识别这些已锁定特征的单一自然观察角度，完整呈现鼠标，保持轮廓和边缘清晰、透视克制、产品不变形。

将鼠标置于无纹理的纯白或近白无缝背景上，画面中只有这个鼠标及其与白色平面的极轻柔、贴合底部接触面的自然阴影；使用均匀、柔和的商业棚拍光，保持参考图的真实颜色和材质层次，让曲面、高光、按键分界和接缝清楚可读，不用戏剧化光线或强烈反射。不得加入场景背景、道具、台座、手、包装、额外配件或参考图中不存在的线缆、文字和 Logo；不得让产品悬浮，不得故意加入污渍、颗粒、噪点、模糊、曝光瑕疵或自然主义“不完美”。
