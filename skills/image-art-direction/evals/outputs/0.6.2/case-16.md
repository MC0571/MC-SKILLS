# CASE 16

一张自然、可信的环境肖像照片：一位普通成年女性独自坐在真实运营中的咖啡店靠窗座位，身体由椅面和靠背自然支撑，重心略向一侧，肩颈放松；一只前臂轻放在木质桌面，另一只手自然落在腿上，手指放松，视线落在桌面前方，表情安静，不像在摆拍。她穿简洁的日常衣物，衣料的垂坠、压痕和褶皱由坐姿、桌边与重力解释，发型整洁自然，皮肤保留真实的明暗和细微纹理，不做塑料感磨皮或过度锐化。

采用环境肖像 / 自然光人像的成像方式，从她斜前方、接近同桌视线的平视机位拍摄中景，画面纳入人物、桌面、靠窗位置和一部分店内空间；人物脸部和上身是唯一视觉中心，背景中的桌椅、玻璃窗、哑光墙面和店内结构清楚但退居语境。使用中等而非极浅景深：人物脸部清晰，近处桌面与背景适度柔化，仍能辨认咖啡店环境，不把背景糊成无意义色块。

主光来自侧窗的柔和日光，方向和衰减自然；室内原有的暖色环境光仅作弱填充，在皮肤、木桌、织物座椅、玻璃和哑光墙面上产生相互一致的反射与漫反射。曝光优先保留脸部肤色和室内中间调，窗边亮部允许轻微自然溢出但不整片死白，暗部仍保留空间层次；不使用无来源的轮廓光、戏剧性彩光或强 HDR。咖啡店保持真实、整洁但非样板间，只出现少量与日常使用一致的痕迹，背景不堆放随机道具、不与人物争夺注意力。

整体像真实相机在日常咖啡店拍到的一刻：自然透视，构图稳定而不僵硬对称，真实材质、可信光影和适度环境景深共同建立真实感。不要用噪点、强运动模糊、歪构图、凌乱头发、夸张皱衣、过曝或随机杂物制造“真实感”；不要时尚大片式摆姿、商业美颜、棚拍级完美背景，也不要把人物与咖啡店环境割裂。
