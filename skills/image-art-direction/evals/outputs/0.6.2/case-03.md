# CASE 03

一张真实、克制的环境肖像，呈现一位年轻女建筑师在建筑事务所工作的瞬间。采用纵向三分之四身中景、接近视平线的自然机位，保留人物与工作空间的清晰关系；她站在工作台一侧，身体三分之四朝向桌面，重心自然落在一侧腿上，微微前倾，左手轻按展开的建筑平面图使纸张保持平整，右手握铅笔在图纸边缘做一个小的修改标记，视线落在图纸与同一项目的实体建筑模型之间，动作像正在思考和核对方案，而不是为镜头摆姿势。她穿简洁、合身但便于工作的中性色西装外套与干净衬衣，发型整齐，服装平整利落，呈现专业可信的职业状态。

场景是一个确实用于建筑设计的事务所工作区：工作台、展开的图纸、正在研究的实体模型、远处少量方案图和有序的材料或书架共同交代职业语境，但都退居 Supporting 与 Context。人物是唯一 Primary，脸部、手部、铅笔、图纸和模型保持清晰，背景有适度景深柔化却仍能辨认办公室的尺度、工作台和空间纵深，不把办公室压成无意义的虚化色块，也不让背景细节与人物争夺注意力。柔和的窗边日光从画面左侧进入，办公桌和墙面提供很弱的环境反射光；曝光优先保证脸部、手部、图纸和模型的层次，光线自然均匀，无戏剧化轮廓光、无强烈彩色灯光。纸张呈哑光纤维质感，模型有清楚而可信的体块边缘，皮肤保留自然纹理，整体色彩干净、专业、略带安静的工作氛围。

画面应像高质量但不夸张的环境职业肖像：真实的工作动作和空间直接证明她是建筑师，构图简洁，姿态放松而有专注感。不要证件照式正面站立，不要双手抱胸直视镜头，不要成功人士宣传海报、夸张微笑或时尚大片式摆姿；不要依赖安全帽、卷尺、卷起的图纸等职业符号堆砌，不加入无关道具。办公室保持整洁、有正常使用痕迹但不故意凌乱；不刻意弄乱头发、服装或空间，不加入垃圾、散乱杂物、过度皱褶、商业磨皮或人为瑕疵。
