# CASE 05

一张方形 1:1 的标准 Catalog / Cutout 产品摄影图，画面唯一的 Primary 是输入参考图中的这一只鼠标，置于均匀、无纹理的纯白或近白色背景中央，四周留出干净而均衡的负空间。将参考图中的产品本体视为 Locked：保持鼠标原有的外形轮廓、长宽高比例、曲面与接缝、左右结构、按键、滚轮、侧键、接口、脚垫、标识和文字（如有）的数量、位置、形状与相互关系；保留参考图已有的颜色、材质、表面处理和细节，不重设计、不改型号，不新增、删除、合并或拆分任何部件。以稳定的略高三分之四目录摄影机位展示顶部、侧面和前后边界，参考图已有明确朝向时优先保持该朝向；产品完整入框，轮廓、按键分界和滚轮清楚可辨，透视克制，比例不变。

鼠标平稳放在白色背景平面上，底部有一圈很轻、柔和且符合接触位置的商业接触阴影，说明产品确实承托在平面上而非悬浮；阴影边缘自然衰减，不形成厚重投影。使用均匀的棚拍商业光：顶部大面积柔光源提供干净的基础照明，左右各有弱而宽的补光帮助描出产品边缘和原有材质，光线方向统一，曝光以鼠标表面、轮廓和细小结构为优先，白色背景保持干净明亮但不吞掉产品边缘。根据参考图中鼠标本来的材质呈现真实的漫反射、细微高光和合理粗糙度；不要凭空增加金属、玻璃或亮面效果，也不要用强反射、戏剧化轮廓光或过度锐化改变表面观感。整只鼠标保持足够景深和清晰度，边缘干净，背景不做场景化虚化。

不要出现桌面纹理、房间或其他场景背景、台座、包装、线缆、手、键盘、电脑、额外配件、第二只鼠标或任何装饰；不要悬浮、倾斜到失去承托关系、裁切掉关键部件或补出参考图中不存在的按钮、孔洞、灯光、品牌和文字。不要故意加入污渍、划痕、灰尘、颗粒、随机曝光瑕疵或“自然不完美”，也不要使用电影化色调、强阴影、彩色光、HDR 光晕或空泛的“奢华”“8K”等标签。
