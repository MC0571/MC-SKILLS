# CASE 03

一张环境肖像 / 自然光人像风格的职业照片：年轻女性建筑师在真实、正在工作的建筑事务所工作区里，站在共享工作台旁，身体以自然的三分之四角度朝向镜头，脸部清楚可见但不直视镜头。她正检查桌上的实体建筑模型和带有标注的图纸，右手用铅笔在图纸上做一个小修改，左手轻扶图纸边缘；视线、手部和上身朝向同一工作对象，动作克制、重心自然，不摆拍。采用视平机位的中景三分之二身构图，同时保留人物、工作台和部分办公室空间。

她穿整洁、低调、适合建筑事务所日常工作的职业装，剪裁利落但不刻意正式，头发和衣物自然整齐，不故意弄乱。工作台上的模型、图纸和少量材料样本是职业语境的支撑信息；背景可见正在使用的工作桌、模型架和图纸墙，但降低对比度与细节密度，不与人物争夺视觉中心。采用来自一侧窗户的柔和自然日光和办公室环境反弹光，人物面部和手部曝光清楚，背景保留适度空间信息而非完全虚化；保持真实摄影的自然动态范围、轻微环境景深和自然皮肤纹理，整体专业、可信、克制，像建筑事务所为成员拍摄的环境职业肖像。

不要证件照式正面站姿、双手抱胸、直视镜头的成功人士海报感；不要用安全帽、卷尺、图纸堆成职业符号，不要过度时尚化、过度生活化或故意凌乱，不要金色夕阳、强人工轮廓光、商业磨皮或把办公室压成无意义的模糊背景。
