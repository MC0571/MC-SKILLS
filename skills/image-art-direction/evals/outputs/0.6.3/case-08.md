# CASE 08

一张横向宽幅的现代公共图书馆建筑可视化，重点是可建造性、空间功能、结构关系、尺度和流线，不是装饰性概念图或酒店大堂。画面展示一个局部双层通高的中央阅览空间：摄影机位于一层主通行带的端部，离地约 1.6 米、接近人的视平高度，以校正垂直线的中等广角直线镜头（约 28mm 等效）向厅内斜向观察；透视开阔但不过度夸张，墙、柱、楼板边缘和书架的垂直线保持稳定。前景通行带连续通向中景的楼梯，视线再延伸到二层连廊和后方阅览区，第一眼同时读出空间很大、确有二层、确有书架和连续的行走路线。

楼梯是一段清晰可见、带真实中间平台的折返楼梯，踏步高度、进深和宽度一致；上下端分别完整落在一层地面和二层楼板，平台由结构支撑，扶手与栏杆连续并牢固连接。二层楼板沿侧墙和规则的柱网展开，楼板边缘、连廊、栏杆与墙体或柱子的连接关系可见，不能像漂浮薄片；楼梯不穿过楼板，连廊与楼梯口保持连续净空。主通行带从摄影机前方经过楼梯平台，再沿二层连廊连接书架和阅览区，阅读桌、座椅和书架不堵住这条流线。

书架只布置有限、可数的几组，沿墙面和清晰轴线排列；每组高度、深度和间距一致，在墙体或端板处自然结束，书架之间留出符合人体尺度的通道，不穿过楼梯、不封堵栏杆，也不向远处无限复制。远侧高窗按结构网格有限排列并在墙边结束，窗框与柱网、楼板保持一致，不出现克隆或漂移的窗格。空间采用功能导向的现代公共建筑材料：哑光浅灰地面、中性墙面、耐用的浅色木质书架和克制的金属栏杆；材料细节真实但不过度装饰，不加入前台、巨大艺术物件、吊灯或奢华大理石来制造酒店大堂感。

少量分散的读者和工作人员只作为尺度参照：前景一人沿主通行带走向楼梯，中景一人在书架端部取书，一组读者安静坐在一层阅读桌旁，二层连廊另有一人行走，远处再保留一位低对比的阅读者。人物大小随距离自然缩放，动作简单、互不纠缠，不直视镜头、不做肖像特写；人物清晰度、对比度和色彩权重低于建筑结构，绝不成为主角。画面左前景只裁入一小段靠近摄影机的结构柱作为低对比 Framing Anchor，增加深度但不遮挡楼梯、楼板连接、书架通道或主要流线。

采用白天的建筑可视化光线：远侧高窗提供方向一致的柔和天光，嵌入式线性照明均匀补足书架和阅读面；光影用于表现空间深度、楼板边缘、栏杆和垂直尺度，所有亮暗与光源方向一致，不使用无来源的戏剧光束、彩色轮廓光或霓虹氛围。曝光保持结构线、楼梯踏步、栏杆、书架通道和人物尺度清楚可读，整体中性、克制、真实；不把受控不完美用于结构，不用歪斜、断裂、随机倾斜或破损制造“真实感”。不要出现断掉或悬空的楼梯、缺失或不等高的踏步、无支撑楼板、错位或悬浮的二层连廊、楼梯穿板、栏杆断裂、漂浮家具、无限重复书架或窗户、克隆人物、人物比例错误、鱼眼或极端超广角透视、酒店大堂感、以及人物压过建筑空间的构图。
