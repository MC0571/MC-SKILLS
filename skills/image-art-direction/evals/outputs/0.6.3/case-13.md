# CASE 13

一张自然主义的上海秋日街拍照片，记录一位成年女性正在普通、无地标性的城市街道上向前行走的真实瞬间。她是唯一明确的主体，穿着简洁、无品牌的秋季日常衣着；服装以有重量感的哑光织物为主，随重力自然下垂，褶皱不规则但合理。她一只脚向前迈步、另一只脚承重，身体重心和肩膀自然配合，手臂放松地随步伐轻摆；视线沿行进方向略偏离镜头，表情平静自然，不回头、不直视镜头、不摆姿势。

采用自然街拍的成像方式，而非商业人像或广告摄影。摄影机在街道侧前方、接近人的视平高度，以约 40mm 等效的正常透视和手持机位拍摄环境中景，人物从头到脚完整入框，保留她与街道的空间关系；构图有轻微抓拍偏移，并在前进方向留出自然空间，人物位于清晰的主要视觉区域。背景只提供上海普通街区语境：低对比的沿街建筑、行道树、路面和功能性街道设施，带有克制的秋季树叶色彩，不出现可识别地标、店铺品牌或可读文字；中远景形成自然纵深，适度景深让人物和脚下路面清楚，远处环境柔和但仍可辨认，不化成无意义色块。

光线来自秋日白天的天空和街道周围表面的柔和环境反弹光，方向一致、对比度适中；皮肤和衣料保留自然中间调与细微纹理，路面和建筑呈真实漫反射。整体色彩低饱和而清爽，以中性灰、米褐、棕褐、暗橄榄和褪金色秋叶建立季节感，不做金色夕阳、浓烈滤镜或无来源轮廓光。行走造成衣摆、发丝和步伐边缘轻微且可解释的运动柔化，脸部与身体主体保持清楚，只有局部边缘留下瞬时动作痕迹，不使用整幅动态模糊；保留真实手持抓拍的自然景深、轻微近距离透视和克制的计算降噪与压缩柔化，曝光自然，人物和关键轮廓始终可读。

不要像广告或时尚写真：不要棚拍式布景、干净抠图背景、精心摆姿、夸张美颜、性感化身体、过度详细的脸部特征、具体身份或复杂剧情；不要出现奢侈品牌、著名上海地标、可读文字、戏剧化灯光、海报式构图、强烈电影滤镜或额外人物和道具成为第二视觉中心。保持非摆拍、非商业、像真实街头即时记录的自然节奏。
