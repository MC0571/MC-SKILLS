# CASE 17

环境肖像 / 自然光人像摄影：一位女性自然站立在真实、具有可辨识空间线索的环境中，完整全身从头顶到鞋底都在画框内，头顶和脚下留出适量呼吸空间，双脚、双手与身体轮廓不被裁切或遮挡；她的脸朝向镜头，五官和眼神清楚可读，姿态放松自然，重心落在一侧，肩胯有轻微而真实的不对称，不摆出僵硬的时尚姿势。使用全画幅相机的 50mm 标准焦段，机位与她的眼睛大致同高，摄影机后退到足以同时容纳完整人物和周围环境的距离，保持自然透视，不产生广角拉伸；高解析度记录脸部细节、全身轮廓、服装与鞋子的纹理。采用中等景深（约 f/5.6），脸部和人物整体保持清晰，背景只轻微柔化，仍能辨认所在地点的空间结构、层次和色彩线索，不把背景化成无意义的虚焦色块。柔和的现有环境光从人物前方略偏侧照亮脸部，皮肤中间调和五官曝光准确，避免强烈逆光或深重阴影；背景亮度和对比度略低于人物，以清晰度、明暗和负空间建立层级，让脸部成为第一视觉锚点、完整身形为第二信息、环境作为可读但不喧宾夺主的语境。真实摄影质感，自然镜头表现；不要超广角透视、不要近距离变形、不要极浅景深、不要强烈背景虚化、不要背景细节与人物争夺焦点，也不要让脸部、手脚或鞋子落入阴影、失焦或画外。
