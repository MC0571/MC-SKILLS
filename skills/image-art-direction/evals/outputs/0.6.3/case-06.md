# CASE 06

一张横向、桌边近距离的手机生活抓拍，记录几位朋友正围坐吃火锅的一个真实瞬间；这是用餐中的纪实照片，不是菜单图或火锅广告。摄影机在一位朋友的座位附近、略高于锅口，以自然的桌面视角轻微向下观察，火锅位于画面中下部并占据最大的清晰区域。火锅稳稳坐在桌面加热底座上，锅底与支撑面有真实接触，锅沿、汤面和桌面之间的前后关系清楚，没有悬浮的锅体。画面第一眼必须先读到滚沸的火锅和大家正在取食的动作。

锅里的汤面小幅翻滚，气泡在液面不同位置破裂，汤汁有自然的薄油光和局部深浅变化；多种火锅食材正在锅中烹煮，彼此有真实的浸没、重叠和遮挡，大小、形状和熟度不完全一致。少量食材被夹到锅沿上方，仍与筷子尖保持清楚接触，受筷子承重向上移动，表面带着合理的汤汁并有一两滴顺重力回落到锅中，不出现漂浮食物。沸腾汤底产生薄而不均匀的热蒸汽，蒸汽只在锅上方和邻近手部周围轻轻扩散，局部柔化后方轮廓，但不变成白雾，不遮住锅沿、主要食物或接触点；锅边可有少量真实的汤汁痕迹和由热气造成的凝结。

朋友只作为 Supporting 和 Context 出现：身体、肩膀、上臂、前臂、手和少量被自然裁切的侧脸从画框四周进入，脸部不需要清楚可辨，也没有人逐一正面对镜头摆拍。用少量简单而互相分开的动作表达一起吃饭，不为每个人设计复杂姿势：画面左前方一位朋友的一只手从画外伸入，握着一双完整筷子从锅沿外侧斜向锅内，夹住一块实际浸在汤里的食材；画面右侧另一位朋友的一只手握着另一双完整筷子，以不同方向靠近锅边，筷尖接触另一处食材但不与前一双交叉；画面下方再有一只手稳稳托着自己的小碗靠近锅边等待取食。三只可辨认的手各自连接到连续的手腕和前臂，其余人的手只在桌边被自然裁切或遮挡，不同时伸入锅中。每一双筷子都只对应一只手，筷子两根成对、长度和夹持关系正常，手指数量、关节弯曲、手腕受力和筷尖接触都可信；筷子不穿透手掌、锅沿或食物，不凭空悬空。

桌面保留真实的用餐进行中状态：几只已经使用过的小碗、蘸料碟、被夹过而不再整齐的食材盘、散放的餐具和一张略有折痕的纸巾，位置有自然错落、轻微沾汤或食物痕迹，但仍然干净可用。食材不按广告样品整齐排列，不把餐桌塞满无关道具；锅、手、筷子、碗和盘子形成可信的前后遮挡，火锅始终压过背景的视觉权重。普通室内用餐空间的现有暖中性顶灯和周围环境反弹光是主要光源，方向和衰减一致：锅沿和湿润食材出现受光方向明确的柔和高光，汤面反射有限，蒸汽被热源上方的光线轻微显现；不添加无来源的彩色轮廓光或戏剧光束。曝光以锅、汤面、夹取中的食材和主要手部为锚点，保留关键材质层次，背景与远处朋友的对比度较低但仍能读出围桌关系。

成像保留手机抓拍的轻微手持构图偏移、自然裁切、适度近距离透视、局部运动造成的轻柔边缘和克制的计算降噪或压缩痕迹；火锅、汤面、主要食材和两组取食动作清楚，远处人物与桌面次要细节略柔和，但不使用过度景深、整幅 HDR、故意脏污、浓重颗粒或严重动态模糊。不要出现多余手指、断裂或融合的手臂、重复或漂浮的筷子、悬空锅体、无来源蒸汽、悬浮食物、无限重复的食材、每个人同时做复杂动作、每个人都面对镜头、完整人物肖像争夺中心、完美广告摆盘、商品摄影式干净布景、海报式构图或模板化滤镜。
