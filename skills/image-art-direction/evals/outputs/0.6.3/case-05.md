# CASE 05

请以提供的鼠标参考图为唯一产品依据，制作一张正规的 Catalog / Cutout 白底产品图。将参考图中实际可见的鼠标视为 Locked：原样保留它的身份、外轮廓、比例、朝向、所有可见部件的数量与位置、按键、滚轮、分件、接缝、固有颜色、材质与表面处理，以及可见文字或 Logo（如有）；不要改按钮、重画结构、增删或合并部件、改变比例、型号或颜色，也不要臆造参考图未展示且无法可靠判断的隐藏结构。沿用能清楚呈现这些已锁定特征的单一自然观察角度，完整呈现鼠标，保持透视克制、轮廓清晰、边缘干净和产品几何不变。

将鼠标置于均匀、无纹理的纯白或近白无缝背景上，画面中只有这一只鼠标。鼠标稳稳承托在白色平面上，底部保留一圈轻柔、贴合接触面的自然接触阴影，阴影向外平缓衰减，足以说明产品落地但不形成戏剧性投影；不得悬浮、失去承托关系或裁切掉关键部件。采用均匀、柔和且方向一致的商业棚拍光，保留参考图的真实颜色和材质层次，让产品表面、轮廓、按键分界、滚轮和接缝清楚可读；白色背景保持干净明亮但不吞没产品边缘，不使用强反射、彩色光、戏剧化阴影或夸张景深。

不得出现房间、桌面纹理或其他场景背景，道具、台座、手、键盘、电脑、包装、额外配件、第二只鼠标，或参考图中不存在的线缆、文字和 Logo；不得加入污渍、划痕、灰尘、颗粒、噪点、模糊、曝光瑕疵、悬浮效果或自然主义“不完美”。不要用电影化色调、HDR 光晕、强烈轮廓光或空泛的“奢华”“8K”等标签改变这张干净、保真的产品图。
