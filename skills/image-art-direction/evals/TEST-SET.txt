IMAGE-ART-DIRECTION REGRESSION TEST SET
目标：测试 skill 是否能把普通用户的不完整视觉需求，转换成完整、连贯、可执行的视觉规格。

==================================================
CASE 01｜亲密感双人手机自拍
==================================================

用户输入：

帮我做一张像晚上随手拍的手机自拍。

一个二十多岁的亚洲女生坐在房间里，灯光是紫色蓝色那种，气氛比较安静。她后面还有一个人，但是我不想看到第二个人的脸，只看到身体和手就好。

后面的人一只手轻轻托着女生的下巴，另一只手搭在她肩膀附近。感觉要亲密自然一点，不要看起来像掐她或者控制她。

女生看起来漂亮，但不要太像AI美女。

测试重点：

- 是否主动确定合理的自拍摄影机关系
- 是否明确第二人物哪些部位入镜、哪些必须出画
- 是否主动设计两只手各自的接触位置
- 是否使用 Contact / Occlusion Geometry
- 是否优先描述正确接触，再针对性排除错误解释
- 是否把最多描述预算投入高风险的手部关系，而不是平均堆细节
- 是否主动补足低光手机摄影应有的成像特征

不希望出现：

- 第二个人的脸
- 多余人物
- 手和脖子融合
- 抓喉咙
- 为了“亲密”自动变成夸张性感姿势

CASE 02｜窗边安静的人像
==================================================

用户输入：

我想要一张很安静的女生照片。

她坐在一个有点旧、有艺术气息的房间窗边，穿宽松的浅色衣服。摄影师好像刚叫了她一下，她正好回头看过来。

我希望它不像时尚大片，更像很多年以后看到还会记得那个下午的照片。

房间里可以有一些雕塑、旧家具之类的东西，但不要布置得特别完美。

测试重点：

- 是否识别为环境肖像 / 自然光人像，而非自动转成 Fashion Editorial
- 是否利用“刚被叫到”解释回头、眼神和身体张力
- 是否主动设计窗光及合理的曝光优先级
- 是否允许窗户等高亮区域适度过曝，而不是强行 HDR
- 是否建立 Pose Naturalism
- 是否加入有限 Controlled Imperfection
- 是否让环境物件成为语境和 Framing Anchors，而不是抢主体
- 是否压制商业大片、美颜、模板摆姿等 Genre Drift

不希望出现：

- 模特式标准姿势
- 金色夕阳大片
- 强人工轮廓光
- 房间完全虚化
- 每一根头发和衣服褶皱都过于完美

CASE 03｜年轻建筑师职业照
==================================================

用户输入：

帮我做一张年轻建筑师的职业照片。

不要证件照那种，希望看起来专业，但也不是那种双手抱胸、很假的成功人士宣传照。

最好能看出来她真的在建筑事务所工作。

测试重点：

- 是否主动把职业通过行为和环境表达，而不是靠符号堆砌
- 是否设计真实的工作动作，例如看模型、图纸或材料
- 是否选择合适的环境肖像方式
- 是否建立人物与办公室背景的视觉层级
- 是否保持职业整洁感
- 是否不会因为学会 Controlled Imperfection 就故意弄乱头发、服装和空间

不希望出现：

- 安全帽 + 图纸 + 卷尺的职业符号堆砌
- 双手抱胸正面看镜头
- 成功人士海报
- 过度生活化或故意凌乱

CASE 04｜黑色腕表高级广告
==================================================

用户输入：

想做一张黑色机械表的高级广告图。

就是那种一看就很贵，但是不要满屏火花、齿轮、烟雾这种很俗的效果。

黑色的表也不能拍成一坨黑，希望能看清楚金属质感和结构。

测试重点：

- 是否主动选择商业产品摄影，而不是情绪化电影摄影
- 是否利用反射塑造黑色结构，而不是单纯提高曝光
- 是否区分拉丝、抛光、玻璃等不同材料
- 是否设计合理背景与台座
- 是否保持产品为唯一 Primary
- 是否不会加入 Controlled Imperfection、随机颗粒、歪构图等自然主义人像规则

不希望出现：

- 纯黑轮廓
- 火花
- 爆炸齿轮
- 漂浮零件
- 大量无意义“奢华”“8K”等词

CASE 05｜普通白底产品图
==================================================

用户输入：

把这个鼠标做成那种很正规的白底产品图就行。

希望干净一点，东西本身不要被改掉。

测试重点：

- 是否主动选择 Catalog / Cutout 产品摄影
- 是否优先产品几何、轮廓、部件数量和比例
- 是否使用均匀商业光和合理接触阴影
- 是否理解“不要被改掉”属于主体硬约束
- 是否主动避免场景化设计
- 是否不会错误套用自然主义摄影的“不完美”

不希望出现：

- 场景背景
- 额外配件
- 改按钮
- 改结构
- 悬浮
- 故意加入污渍、颗粒或曝光瑕疵

CASE 06｜热闹的火锅照片
==================================================

用户输入：

想做一张朋友一起吃火锅的照片。

重点还是火锅和那种大家一起吃东西的热闹感觉，不需要每个人都清楚露脸。

希望真实一点，别像把所有菜整整齐齐摆好以后拍广告。

测试重点：

- 是否主动把火锅设为 Primary
- 是否通过手、筷子、食物建立“聚餐”而非依赖完整人物
- 是否控制多人手部和筷子的 Interaction Complexity
- 是否主动避免给每个人设计复杂动作
- 是否处理蒸汽、汤汁、食材的真实材质
- 是否建立合理遮挡
- 是否保留一定现场随机性但不制造结构错误

不希望出现：

- 多余手指
- 重复筷子
- 漂浮食物
- 每个人都面对镜头
- 完美广告摆盘

CASE 07｜香水瓶
==================================================

用户输入：

我想拍一个很简单但很高级的香水瓶。

瓶子是透明玻璃的，盖子是黑色的。不要加太多装饰，我主要希望玻璃看起来是真的，而且有重量，不像透明塑料。

测试重点：

- 是否主动处理透明玻璃需要背景关系、厚度、折射和边缘反射
- 是否分别处理玻璃与黑色瓶盖
- 是否通过光学行为表达“重量”和真实材质
- 是否把触觉/抽象感受翻译成视觉属性
- 是否不为了“高级”自动增加金色、烟雾、水珠和豪华道具

不希望出现：

- 塑料透明感
- 黑色瓶盖完全没有层次
- 无来源水珠
- 金色豪华装饰
- 过度情绪化场景

CASE 08｜现代图书馆
==================================================

用户输入：

帮我做一个现代图书馆内部。

希望看起来真的能建出来，也能看出空间很大，有楼梯、有二层、有书架，也有一些人在里面。

我不想要那种AI建筑图，一看楼梯和楼板就不合理。

测试重点：

- 是否优先空间功能、结构、尺度和流线
- 是否主动设计摄影机位置
- 是否合理使用人物作为尺度参照
- 是否控制书架、窗户等重复结构
- 是否建立真实楼梯—楼板—连廊关系
- 是否可使用少量 Framing Anchors 增加深度，但不机械遮挡
- 是否不会把 Controlled Imperfection 应用为结构错误

不希望出现：

- 断掉的楼梯
- 无支撑楼板
- 无限重复书架
- 酒店大堂感
- 人物成为主角

CASE 09｜雨夜科幻悬疑
==================================================

用户输入：

想做一个雨夜的科幻电影画面。

一个女侦探好像刚在巷子里发现了什么重要东西，她蹲下来查看。

希望有点赛博朋克，但别搞成满大街都是粉蓝霓虹灯那种俗套效果。主要还是悬疑和紧张感。

测试重点：

- 是否通过“刚发现东西”建立 Narrative Moment 和 Blocking
- 是否主动设计证物与人物视线关系
- 是否建立雨 → 湿地面 → 反射的因果链
- 是否使用场景中合理存在的城市灯、车辆灯、室内灯
- 是否识别并压制“赛博朋克 = 满屏霓虹”的 Genre Drift
- 是否避免英雄战斗姿势

不希望出现：

- 满屏霓虹
- 持枪英雄 pose
- 无来源彩色边缘光
- 湿地面但没有雨或其他原因
- 动作海报感

CASE 10｜参考照片高级化，但不要改人
==================================================

用户输入：

这张照片里的人我很满意，不要改她。

我只是觉得现在背景和光线有点普通，想让照片看起来更高级、像杂志一点。

但是脸、头发、衣服和姿势都不要动。

测试重点：

- 是否建立 Locked / Editable
- 是否把人物身份、脸、发型、服装、姿势全部锁定
- 是否只重新设计背景、灯光、色彩和允许范围内的摄影质感
- 是否防止 Editing Drift
- 是否不会把“高级”理解成重新设计人物
- 是否不会自动增加首饰、妆容或改变体型

不希望出现：

- 换脸
- 改发型
- 改衣服
- 改姿势
- 加首饰
- 自动瘦脸或改变年龄

CASE 11｜用户给了很多“或者”
==================================================

用户输入：

想做一个女生在漫展的真人Cosplay照片。

衣服可以是黑色短裤或者长裙，道具可以拿法杖或者剑，背景可以在漫展里面，也可以像专业摄影棚。

反正希望最后看起来比较真实、比较酷。

测试重点：

- 是否识别这些都是高显著性未闭合决策
- 是否主动选择一套视觉上互相支持的方案
- 是否不把 brainstorming 原样塞进最终 Prompt
- 是否基于“真实真人 Cosplay”选择最合理场景和媒介
- 是否最终形成单一、完整、可执行的画面

不希望出现：

最终 Prompt 仍写：

- 短裤或长裙
- 法杖或剑
- 漫展或摄影棚


==================================================
CASE 12｜背景细节用户根本不在乎
==================================================

用户输入：

背景不用特别具体，反正就是一个昏暗的私人房间。

她后面隐约有个深灰色的软软的家具就行，是椅子还是床我都无所谓，而且背景本来就应该很糊。

测试重点：

- 是否识别这是低显著性不确定性
- 是否使用语义抽象而不是强行做决定
- 是否不会询问用户“到底是椅子还是床”
- 是否不会在最终 Prompt 保留显式“A 或 B”

理想方向：

“背景中隐约可见一件深灰色软体家具。”

而不是：

“椅子或床。”

CASE 13｜一句话街拍
==================================================

用户输入：

想要一张上海秋天街上走路的女生照片，自然一点，不要像拍广告。

测试重点：

这是一个高价值的极简输入测试。

检查 skill 是否能自行合理补全：

- 成年人物
- 环境语境
- 行走动作
- 自然视线
- 街拍 Imaging Mode
- 合理摄影机
- 秋季材质与色彩
- 环境景深
- 行走造成的轻微运动
- 非摆拍感

同时不要自行补充：

- 具体身份
- 极其详细的脸
- 性感化身体
- 著名上海地标
- 奢侈品牌
- 复杂剧情

CASE 14｜一句话产品需求
==================================================

用户输入：

帮我把一杯冰咖啡拍得特别有夏天的感觉，但还是要像真的咖啡，不要太广告。

测试重点：

检查 skill 是否能从模糊情绪词“夏天”转译为可观察视觉规格，例如：

- 冷饮凝结水珠
- 冰块
- 适当环境光
- 清爽但合理的色调
- 玻璃与液体材质
- 合理背景语境

而不是简单生成：

- 蓝天
- 海滩
- 棕榈树
- 大量柠檬
- 阳光光斑
- “summer vibes”

验证 Creative Intent → Material / Lighting / Context 的翻译能力。

CASE 15｜抽象触觉需求
==================================================

用户输入：

我想拍一张女生的近照，皮肤看起来要很柔软、很干净，有一点凉凉的感觉，但不要像塑料娃娃。

测试重点：

专门测试 Haptic-to-Visual。

检查 skill 是否：

- 把“柔软”转译为合理的表面响应
- 保留细微皮肤纹理
- 避免蜡质高光
- 不机械把“凉凉的”直接翻译成蓝色皮肤
- 根据上下文决定色调，而不是由触觉词强行决定颜色

不希望出现：

- 冰蓝肤色
- 塑料皮肤
- 极端磨皮
- 过度毛孔锐化

CASE 16｜“真实一点”压力测试
==================================================

用户输入：

做一个普通女生坐在咖啡店里的照片，真实一点就行。

测试重点：

这是 Controlled Imperfection 的压力测试。

检查 skill 是否理解：

“真实一点”

不等于自动加入：

- 噪点
- 强运动模糊
- 歪构图
- 凌乱头发
- 皱衣服
- 过曝
- 随机杂物

应该首先通过：

- 合理姿态
- 环境光
- 真实材质
- 自然景深
- 人物与咖啡店环境关系

建立可信度。

只有 Creative Intent 支持时，才增加少量受控不完美。

CASE 17｜用户提出摄影上互相牵制的要求
==================================================

用户输入：

我想拍全身，但是又希望她的脸能看得很清楚，背景也最好能看出来是什么地方，不要糊得什么都没有。

测试重点：

检查 skill 是否能解决：

- 全身人物
- 脸部可读性
- 环境可读性

之间的视觉资源冲突。

应该通过：

- 适当拍摄距离
- 合理焦段
- 足够分辨率
- 适度而非极浅景深
- 简洁背景层级

协调。

不应该：

- 机械要求超大光圈
- 同时要求极强背景虚化
- 因为用户没给焦段就询问用户

帮我做一张一个男人晚上坐在车里的电影感照片，有点孤独。

- 车内空间
- 合理 practical lighting
- 摄影机位置
- 夜景曝光

- 适合的色彩和对比

而不是简单堆：

cinematic
moody
dramatic lighting
35mm
film grain
teal and orange
masterpiece
