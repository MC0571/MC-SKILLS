# 主体与场景 Playbooks

## 何时读取

当原始需求信息不完整，需要为特定主体补全专业视觉规格时读取。只使用当前任务对应的 playbook。

Playbook 用于补全该领域让画面成立所需的专业关系，不替用户完成新的主题设计。优先补全“如何成立”，谨慎补全“具体是什么”：火锅场景需要合理的锅、蒸汽、手和筷子关系，但未指定时不必决定精确人数、锅底类型和完整菜品列表；建筑需要合理结构、尺度和流线，但未指定时不必自动完成具体材料概念；电影场景需要 blocking 和 motivated lighting，但不因为可以设计就增加过多独立 practical source 或角色背景事件。

## 人像

建议顺序：

`身份与用途 → 可识别外观 → 服装与材料 → blocking → 手部与道具 → 摄影机 → 背景分离`

- “专业”“自然”“高级”必须转成姿态、视线、服装材料、环境线索和光线。
- 脸、发型和服装的细节量服从景别；远景不承担精细五官。
- 多人近距离或局部陪体构图中，明确次要主体的画内、画外范围以及与主人物的接触几何；只需要手、手臂或躯干时，不自动补全第二张脸或完整人物。
- 背景用于解释职业、地点或生活状态，不堆砌身份符号。
- 常见风险：证件照式正面站姿、模板化面孔、手部无目的、背景与人物同等清晰。

### 自然主义人像

当用户明确要求自然主义、非摆拍、私密、安静、松弛、生活化、抓拍感或其他等义视觉方向时启用；英文表述可能包括 candid、intimate、quiet、natural、editorial naturalism 或 non-posed，但不把固定标签作为主要匹配规则。

检查表情是否来自当前情境，重心和支撑是否成立，手部动作是否必要，坐姿、倚靠或转身是否形成合理身体关系，服装是否响应重力与接触，发型是否被无意商业化或沙龙化，是否出现不必要的商业修图和模板姿态，以及环境是否仍像真实空间。

可以用一个极短的“前一刻发生了什么”解释表情和姿态，但不自动给普通职业肖像、证件照或商业人像添加故事、散乱头发、衣物滑落、不稳定姿态或生活化瑕疵。

## Cosplay 或角色真人化

建议顺序：

`角色识别轮廓 → 服装层级与色块 → 现实材料转译 → 标志性道具 → 真人动作 → 实际拍摄环境`

- 把虚拟材质转译为可缝制织物、皮革、金属、木材或涂装树脂，不保留无解释的 CG 表面。
- 标志性道具需明确数量、位置、握持、重量和遮挡。
- 常见风险：塑料服装、道具重复、手穿过握把、装饰悬浮、角色特征被普通人像美化覆盖。

## 产品

建议顺序：

`产品几何与比例 → 轮廓和接口 → 表面 finish → 摆放和接触 → 反射设计 → 尺度 → 背景关系 → 品牌与文字保真`

- 先锁定结构，再谈氛围；黑色、金属和玻璃读取 `lighting-materials.md`。
- Hero Shot 用单一主观察角度、清楚轮廓和受控反射建立价值中心；Macro 只表现当前景别真正可见的工艺；Lifestyle 用可信使用关系提供语境，不让环境压过产品。
- Catalog / Cutout 以真实颜色、完整边缘、干净背景和合理接触阴影为主，不自动加入戏剧化道具。
- 常见风险：比例或结构畸变、部件重复、黑色糊成一片、玻璃失去厚度、表盘或标签乱码、产品悬浮、环境尺度错误。

## 食物

建议顺序：

`食物结构 → 表面与内部可见性 → 温度线索 → 摆盘 → 餐具或人物互动 → 光线`

- 酥脆、湿润、柔软、热或冷必须通过可见的表面和物理状态表达。
- 不改变用户要求保留的摆盘、熟度、切面和配菜关系。
- 常见风险：不可见内部被强行描述、蒸汽无热源、食材重复、塑料油光、手和筷子畸变。

## 建筑与室内

建议顺序：

`功能 program → 体量和结构 → 流线 → 开口 → 材料 → 尺度参照 → 观察点 → 时间与天气`

- 摄影机位置必须能解释空间关系；不要让夸张广角代替真实尺度。
- 白模转写实时先锁定体量、柱网、门窗和视角，再添加材料、光线与环境。
- 常见风险：无支撑楼板、断裂楼梯、重复窗户、人物尺度错误、结构被景观遮挡。

## 电影场景

建议顺序：

`剧情瞬间 → 角色目标 → blocking → production design → 摄影机 → motivated lighting → 媒介响应`

- 选择一个动作发生的瞬间，不用海报式姿势代替叙事。
- 环境、道具和光源应解释角色为何这样行动。
- 常见风险：只有类型标签、所有人物看镜头、背景特效无原因、剧情要求在单帧中不可见。

## 历史复原

建议顺序：

`时代与地点 → 建筑和空间功能 → 服饰与器物 → 人物活动 → 观察点与成像媒介`

- 把时代特征落实到构造、材料、服饰、器物和活动方式，不用单一装饰符号代替整体环境。
- 未指定且不影响当前画面成立的历史细节保持克制或抽象；只有当前可见结构必须闭合时才选择一个低承诺方案，不并列堆叠多个版本。
- 常见风险：影视城式过度装饰、混入其他时代符号、现代材料与生活方式穿帮。
