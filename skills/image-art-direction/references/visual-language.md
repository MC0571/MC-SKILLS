# 视觉语言与镜头组织

## 何时读取

用于剧情瞬间、多人 blocking、复杂构图、镜头选择、主体分离、可见性或因果关系需要进一步设计的任务。

## 从叙事瞬间开始

先确定一个能被单帧观察的瞬间：

- 谁正在做什么；
- 这个动作刚发生、正在发生还是即将发生；
- 哪个可见结果证明了它；
- 观众第一眼必须理解什么。

“紧张”“高级”“电影感”不是动作。把它们转成姿态、距离、视线、接触关系、空间阻隔或环境变化。

人物肖像或电影场景可以用极短的“前一刻发生了什么”解释当前可见的视线、姿态、动作惯性和情绪张力，但微叙事必须保持最低承诺。例如摄影师刚叫她、她正在回头；他停车后独自坐在驾驶席里、长时间望向窗外；她刚发现地上的物体、正在低头确认。

不要未经用户暗示创造画面之外的具体背景事件，例如失恋、争吵、无人回应的电话、死亡消息、追捕原因或特定人物关系，仅为了给情绪寻找解释。微叙事负责解释可见状态，不负责替用户编写角色背景。

## Blocking

- 先从剧情、职业任务或产品交互推导动作，再确定主体的位置、朝向和视线。
- **Action Economy**：每个显著动作都应服务剧情、工作、产品交互或人物关系。无作用的手势会增加手部失败风险并削弱自然感；没有动作需求时，允许手自然处于低信息量位置。
- 接触关系要描述双方：手如何握住道具，道具哪部分被遮挡，重量如何影响手腕或身体。
- 多人画面先确定角色功能，再决定人数；无叙事作用的人群只作为环境语境。
- 动作的结果应可见：行走可以带动衣摆，雨水会改变表面，热源可以产生蒸汽，重量会改变材料受力。

### Pose Naturalism

自然姿态不是随机打乱肢体，而是让身体同时响应重力、支撑面、重心、关节放松、动作惯性和服装张力。可保留轻微肩高差、非镜像肢体关系、放松关节、坐姿压缩、一侧承担更多重量，以及衣料和发丝的轻度不规则。

避免数学般均衡的肢体角度、两侧镜像姿态、每只手都承担一个“时尚动作”，也不为自然感制造畸形关节。

### Controlled Imperfection

画面的不完美只有在符合成像媒介和主要意图时才有价值。可选项包括轻微构图偏移、自然裁切的次要物件、有限高光溢出、散乱发丝、不规则褶皱、非完美对称姿态、轻度光学柔化或小型使用痕迹。

每一项都应增强可信度、自然感或媒介一致性；不要机械加入噪点、模糊、歪斜、过曝或杂物，也不要把技术错误称为受控不完美。

## 摄影机是信息选择器

按需要展示的信息选择景别，而不是从默认焦段开始：

- 远景适合空间、尺度和群体关系，不承担微观服装或表面细节。
- 中景适合动作、道具和环境关系。
- 近景适合表情、接触点或材料细节，但会牺牲整体空间。

检查摄影机高度、角度、主体朝向和遮挡。被裁切、背向镜头、藏在封闭物内部或处于强逆光暗面的信息，不应同时承担主要视觉任务。

典型冲突包括：三分之四身构图要求鞋底细节、封闭食物要求内部组织、背向镜头的人物要求胸前饰品，以及极远景要求微观面料纹理。必须展示时，调整景别、摄影机、朝向、姿态、切面或遮挡关系。

## 视觉层级

在内部给元素分级：

1. **Primary**：第一眼必须识别的主体或动作。
2. **Supporting**：解释主体身份、动作或产品价值的信息。
3. **Context**：交代地点、尺度、时代或氛围的背景线索。

通过清晰度、对比度、尺寸、位置、颜色和负空间分配权重。背景不是越详细越真实；它只需要提供足够语境。

前景、中景和背景用于组织深度与关系，不是机械填满三层。主体分离可来自明暗、色彩、清晰度、边缘或负空间差异；选择最符合当前媒介的一种或两种，不同时堆叠全部手段。

Prompt 的描述密度大致服从视觉层级，并再考虑生成失败风险：高显著性、高风险关系最详细；低显著性、低风险语境最简略。

### Framing Anchors

局部进入画框的前景或边缘物件可以建立深度、暗示环境、提供时代语境或平衡画面边缘，例如被裁切的石膏像、门框、近前景椅背、植物或建筑构件。它们必须属于当前空间、符合摄影机位置、不抢夺 Primary，且裁切不能造成结构误读。不要为了“层次感”给每张图机械添加模糊前景。

## 因果一致性

用“原因 → 表面或动作响应 → 成像结果”检查视觉效果：

- 雨和车辆灯 → 湿路面反射 → 夜景中的方向性高光；
- LED 屏 → 冷色环境光 → 临近表面出现相应反射；
- 沸腾汤底 → 蒸汽 → 局部遮挡与高光扩散；
- 山坡地形 → 分层结构与挡土 → 建筑尺度和受力可信。
- 人物正在查看模型 → 视线和上身朝向模型 → 动作显得自然且职业身份可读。

承担真实性、叙事或结构解释的关键效果应有合理来源或场景原因，光源可以位于画外。低显著性的氛围处理如果符合成像媒介和美术方向，可以受控保留；但不能遮挡关键结构、制造错误物理关系，或成为主体可信度的唯一依据。

## Decision Closure 示例

- `入口或二层连廊拍摄` → `从二层连廊的视平高度观察大厅`；
- `短裤或裙子` → 根据角色轮廓选定其中一个；
- `展会或摄影棚` → 根据成像媒介选定现场抓拍或棚拍。
- `暖光或冷光` → 根据可见光源和主要情绪选定一种主导色温。
- 背景中的 `椅子或床` → 抽象为 `炭灰色软体家具`；低显著性语境无需保留显式分支。

## 校准示例

低信息量：

> luxury black watch, cinematic lighting, masterpiece, 8K, dramatic

更可执行：

> 黑色机械腕表以三分之四角度置于石墨灰台座上，狭长侧光形成可控反射，分别勾勒拉丝表面和抛光倒角；背景低对比，视觉中心只落在表盘与表壳结构。

差别不在长度，而在主体、观察点、光源、材料响应和视觉层级已经闭合。
