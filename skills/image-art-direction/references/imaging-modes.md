# 成像媒介与生产方式

## 何时读取

当用户只给出“真实”“电影感”“杂志感”等模糊表述，或多个成像方式可能冲突时读取。

## 选择规则

成像媒介不是装饰风格，而是一份生产合同。每个最终 prompt 选择一个主媒介；其他特征只能作为辅助，不能同时要求互相矛盾的成像规律。

| 主媒介 | 核心控制 | 合理痕迹 | 避免 |
|---|---|---|---|
| 手机抓拍 | 近距离、自然机位、环境光、即时动作 | 轻微近距离透视、局部曝光或动态范围处理、适度降噪造成的细节柔化、少量运动柔化或压缩 | 棚拍级完美反射、无来源轮廓光、机械添加传感器噪点或胶片扫描特征 |
| 自然街拍 | 人物与真实街道互动、环境语境、抓拍节奏 | 行人或衣摆轻微运动、自然景深 | 正面证件照姿势、过度清空背景 |
| 纪实或报道摄影 | 任务驱动动作、现场关系、环境语境、记者视角 | 混合环境光、适度高感、局部运动柔化、自然遮挡 | 英雄海报姿势、无来源戏剧光、过度清场、宣传照式构图 |
| 环境肖像 / 自然光人像 | 人物与真实环境的可读关系、自然或可信环境光、人物为 Primary 且保留空间语境 | 自然动态范围、适度环境景深、环境反弹光；按 Creative Intent 允许有限受控不完美与高光溢出 | 商业时尚化、无动机模特姿势、环境被虚化成无意义色块、默认硬轮廓光、默认商业磨皮、默认金色夕阳调色 |
| 杂志编辑写真 | 明确的人物身份、姿态、造型和背景关系 | 修图强度服从编辑方向；自然主义方向可保留少量受控不完美 | Catalog 式抠图、模板化成功人士道具、把不完美当默认风格 |
| 电影剧照 | 单一剧情瞬间、blocking、production design、motivated lighting | 与选定拍摄介质一致的颗粒、运动和高光响应 | 只有“cinematic”标签、无剧情的海报姿势 |
| 商业产品摄影 | 几何、边缘、反射、接触关系和视觉中心 | 高光形状可控、背景干净、局部高解析 | 随机运动模糊、夸张景深、结构漂移 |
| Catalog / Cutout 产品摄影 | 产品几何、真实颜色、清晰轮廓、白色或透明背景 | 按需求保留轻微接触阴影或完整抠图边缘 | 戏剧化背景、无关配件、结构和 Logo 漂移 |
| 美食摄影 | 结构、表面、温度线索、摆盘与用餐语境 | 蒸汽、凝结、碎屑或融化仅在物理合理时出现 | 不可见内部、塑料高光、无限重复食材 |
| 建筑摄影 | 真实观察点、尺度、材料、自然或现有人工光 | 合理天空反射、垂直关系和人物尺度参照 | 夸张超广角、无来源补光、结构漂移 |
| 建筑可视化 | 几何、结构、材料、流线、时间和环境状态 | 一致的透视、表面响应和尺度参照 | 无支撑结构、窗户漂移、只靠气氛掩盖空间问题 |

商业产品摄影可按单张画面的目的选择：Hero Shot 强调轮廓与主要价值；Macro 强调可见的工艺和材质；Lifestyle 让产品进入可信使用环境但仍保持主体地位。Catalog / Cutout 则优先保真、轮廓和背景分离。

Controlled Imperfection 是由 Creative Intent 触发的选择，不是任何成像模式的默认属性。Catalog / Cutout、商业产品、建筑等任务不会因此自动加入歪斜、污渍、过曝、模糊、噪点或前景遮挡。

环境肖像 / 自然光人像优先人物与真实空间的自然关系，姿态可自然主义但不默认时尚摆拍；景深可以柔化环境，却要保留足够空间信息。杂志编辑写真则可以有更明确的造型、编辑和视觉设计意图。

### 自拍或前置镜头

自拍是一种特殊的 camera–subject relationship。需要时明确谁持有手机、持机手臂向哪个画框边缘延伸、设备是否在画外、人物看向镜头还是略过镜头，以及近距离产生的透视关系。前置镜头可有克制的计算摄影或美颜处理，但不同时采用明显第三人称机位和无法成立的自拍手臂几何。

## 从用途反推媒介

- “像路人拍到”通常收敛为手机抓拍，而不是商业人像。
- “人物与工作或生活空间自然共存”通常收敛为环境肖像 / 自然光人像，而不是杂志编辑写真。
- “现场训练或应急演练”通常收敛为纪实或报道摄影，而不是英雄宣传照。
- “菜单图”通常收敛为受控美食摄影，而不是餐桌纪实。
- “高端腕表广告”通常收敛为商业产品摄影，而不是电影剧照。
- “纯白背景产品图”通常收敛为 Catalog / Cutout 产品摄影，而不是商业 Hero Shot。
- “空间尺度和自然采光”根据输入是实景还是未建成方案，收敛为建筑摄影或建筑可视化。

选择媒介后，把不属于它的噪点、焦段、光线和后期术语删除。成像痕迹应由媒介产生，而不是单独作为“真实感”装饰。
