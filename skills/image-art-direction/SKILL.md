# Image Art Direction

把图像请求当作一次完整的视觉制作，而不是关键词堆叠。先设计一张具体画面，再把它编译成图像模型容易执行的自然语言规格。

## 确定交付意图

根据请求选择实际需要的工作，不把每次请求都扩张成完整制作流程：

- **只写提示词**：交付可直接使用的最终提示词。
- **生成图像**：整理必要规格后生成并交付图像。
- **编辑或重制**：先检查目标图像，建立锁定项与可编辑项，只改变用户允许修改的内容。
- **评审或解释**：区分可见内容、视觉判断和改进建议；不擅自生成新图。
- **定向修订**：只修正用户指出或检视发现的实质偏差，并保留已经成功的特征。

对不会改变主题、身份、叙事含义或主要视觉方向的低风险实现细节，可以结合用途做最小必要推断。未指定的高显著性事实优先保持抽象，不因为“可以设计”就主动具体化。

只有当视觉决策是让画面可执行、满足主要意图、解决可见性或物理关系，或控制高概率生成失败所必需时，才主动补足。不要未经用户暗示新增具体地点、背景事件、人物经历、时代、产品结构、食物种类、建筑风格、品牌或其他会改变画面语义的主题性事实。

未指定的身份属性默认不可推断，包括性别、族裔、年龄细分、身材、固有肤色、发色和具体面部类型；仅在用户语言已经蕴含、参考图明确可见或任务逻辑确实要求时具体化。未指定的高显著性场景类别同样保持抽象，例如不因画面需要背景就自行选择室内或室外、城市或乡村、古典或现代。

能够用中性类别完成画面时优先使用中性类别。未知不等于待填空。只有缺失信息会实质改变主题、身份、硬约束或交付结果，且无法通过低承诺抽象解决时才询问用户。

## 提取约束

在内部区分约束，不要求向用户展示标签：

- **硬约束（Hard constraints）**：身份、主体数量、几何与结构、文字与品牌、指定画幅、关键位置关系，以及用户明确要求保持的参考内容或时代边界。
- **软偏好（Soft preferences）**：情绪、色彩倾向、背景丰富度、一般光线风格、颗粒强弱和装饰性细节。

参考图任务同时建立：

- **锁定项（Locked）**：用户明确要求保持、参考图中实际可见，或由用户提供的可靠信息明确规定的身份、几何、数量、比例、位置、姿态、结构、文字、Logo 和其他特征。
- **可编辑项（Editable）**：用户允许修改的环境、光线、天气、材质、色彩、背景或构图范围。

不可见、未提供或无法从参考可靠判断的结构，不因为同类对象通常如此而自动升级为 Locked。任务不需要展示未知区域时保持不声明；必须展示且该结构属于高显著性硬信息时，按现有询问规则处理。

Locked 优先锁定主体的固有内容与结构，不自动锁定全部原始成像结果：

- **Content / Structure**：身份、五官几何、轮廓、发型结构、姿态、产品几何、服装结构、固有材质，以及用户要求保持的基础颜色；
- **Rendering / Illumination**：受光明暗、阴影、环境反射、曝光、局部色温和整体调色。

只重新设计 Editable；不把“高级化”“写实化”或“提升品质”解释为重新设计主体，也不静默收窄 Editable。用户允许修改某一区域时，不自行给该区域增加新的语义锁定；仅为保持硬约束、几何、接触或透视连续性而限制必要部分。用户允许修改光线时，可以让同一个 Locked 主体接受新的合理照明，但不得借光照改变身份、几何、材质身份、固有颜色、服装结构或姿态。用户参考中的 Locked 优先于自动补全；Logo、包装文字和已知精密产品结构默认不重新设计。

约束看似冲突时，先区分目标与实现手段，并寻找不改变主要意图的唯一合理解。只有存在多个同等合理方案，且选择会实质改变主题、身份、硬约束或交付结果时才询问用户。

## 视觉设计

只构建会影响当前画面的部分，不把这些维度强制输出成表格：

1. **创意意图（Creative Intent）**：确定用途、受众、主要视觉意图和情绪。
2. **成像媒介（Imaging Mode / Medium）**：先确定这张图假定由什么生产方式产生，例如手机抓拍、杂志写真、电影剧照、商业产品摄影、Catalog / Cutout 产品摄影或建筑可视化；后续镜头、光线、材料与成像痕迹服从这个媒介。
3. **美术指导（Art Direction / Mise-en-scène）**：让主体、造型、道具、环境和色彩属于同一个视觉世界。
4. **动作与场面调度（Blocking / Interaction）**：确定主体的位置、朝向、视线、动作、手部、接触关系以及动作造成的可见结果。明显动作优先来自剧情、职业活动、产品操作或人物关系；没有动作需求时，让主体保持自然、低复杂度状态。自然主义姿态或摆放应服从重心、支撑、连接关系、材料重量和当前动作，不使用结构错误制造“不完美”。
5. **镜头设计（Camera / Shot Design）**：按需要展示的信息选择景别、机位、距离、构图、焦点和画幅。
6. **合理光源（Motivated Lighting）**：说明关键光线的来源、方向、颜色、软硬，以及它如何作用于主体和材质。
7. **视觉层级（Visual Hierarchy / Gestalt）**：区分主视觉、支撑信息和环境语境；除非叙事需要多中心构图，不让背景拥有与主体相同的视觉权重。
8. **材质定义（Material Definition）**：用具体材料及其透明度、粗糙度、反射和形变替代空泛的质量形容词。
9. **物理与摄影可信度（Physical / Photographic Plausibility）**：让结构、受力、表面、景深、运动、曝光和成像痕迹符合选定媒介。自然主义、纪实或特定编辑方向可选择少量与媒介和意图一致的受控不完美；它们必须增强可信度，不能合理化结构错误、畸形或随机噪声，也不是越多越真实。
10. **因果一致性（Causal Coherence）**：让动作、姿态、环境状态、光照、材质变化、运动和成像痕迹具有可解释的原因。优先写产生视觉结果的原因，不孤立堆叠反射、烟雾、边缘光或动态模糊。

- 剧情瞬间、blocking、自然姿态、摄影机、构图锚点、受控不完美、可见性、视觉层级或因果组织较复杂：读取 [visual-language.md](references/visual-language.md)。
- 曝光策略、触觉词转译、黑色物体、金属、玻璃、液体、织物、皮肤、食物或混合光源是关键：读取 [lighting-materials.md](references/lighting-materials.md)。

## Prompt 编译

把已完成的画面设计翻译成模型容易执行的指令：

1. **实体 → 属性 → 关系**：把属性紧邻所属实体；明确数量、相互位置、接触和遮挡。用户使用“一些”“少量”“几个人”等近似数量时保持近似，不升级为精确数字；只有精确数量属于硬约束或构图成立所必需时才给出数字。方向容易混淆时使用 `image-left`、`image-right` 等观众视角，并保持一致。
2. **接触与遮挡几何（Contact / Occlusion Geometry）**：复杂交互按需要明确参与双方、接触部位与目标区域、接近方向、压力或重量、遮挡顺序，以及必须保持可辨认的轮廓、负空间或间距。不只使用“握住”“抱住”“靠着”等抽象动词。
3. **可见性与画框参与（Visibility / Frame Participation）**：检查关键规格在当前裁切、朝向、遮挡、景深和光线下是否可见。局部入镜主体需明确画内部位、画外部位、进入画面的边缘、是否允许脸部出现，以及可见部分与主主体的关系；不让模型自行补全为完整人物。
4. **按显著性闭合决策（Decision Closure by Salience）**：关闭影响身份、轮廓、动作、摄影机、主要环境、关键道具、光线逻辑或主要意图的高显著性分支。低显著性选项具有相同视觉作用时，抽象为共同类别；仅在用户明确要求变化性或多个版本时保留分支。最终输出前检查描述场景内容的显式备选表达，如 `A 或 B`、`A/B` 或 `A or B`：高显著性分支选定一个，低显著性且同作用的分支抽象为共同类别。
5. **最低充分补全（Minimum Sufficient Completion）**：只补足让画面成立所需的具体性。新增细节必须服务硬约束、主要视觉意图、可见性、blocking、因果关系、材料表现、媒介可信度或高风险失败控制；否则优先删除或抽象。Completion 是补足画面成立所需信息，Closure 是收敛用户已提出或设计必须解决的分支，Invention 是创造用户未暗示且画面不需要的新主题性事实；前两者允许，第三者默认避免。
6. **显著性加权的信息与具体性预算（Salience-weighted Information Budget）**：按“视觉重要性 × 生成失败风险”分配描述密度，并控制具体性。Primary、用户明确关心的特征、关键识别信息和高风险关系可以更具体；Context 与低风险 Supporting 优先使用较宽类别。新增数量、品种、地点、建筑材料、独立光源、道具或剧情事实前，先确认它会改善主要体验或解决真实生成问题。不要因为知道怎样描述一个细节，就把它加入画面。
7. **交互复杂度（Interaction Complexity）**：每个握持、穿戴、遮挡、交叉、人物接触或物体嵌套都增加关系漂移风险；只保留具有视觉或叙事价值的交互。
8. **失败感知约束（Failure-aware Constraints）**：先用正向几何定义正确的接触、位置、遮挡和可见边界，再用少量负面消歧排除最可能的错误解释。负面词不能代替正确几何，也不复制通用负面词库。

使用具体名词、动作、材料和空间关系；`masterpiece`、`stunning`、`8K` 等标签不能代替可观察的视觉规格。只写有作用且彼此一致的镜头、光线与媒介参数。

原始需求缺少领域规格且主 skill 不足以合理补全时，读取 [subject-playbooks.md](references/subject-playbooks.md) 中当前主体对应的部分；不要扩展到无关领域。

## Execution Gate

在最终生成或交付提示词前内部检查，不默认展示：

1. 用户的硬约束和 Locked 是否全部进入最终规格，且未被后续设计覆盖；
2. 主体数量是否明确；
3. 属性是否绑定到正确实体；
4. Blocking 与高风险接触的接触点、方向、遮挡、受力和关键边界是否成立；
5. 关键视觉信息及局部入镜主体的画内、画外边界是否符合摄影机和裁切；
6. Primary 是否明确，支撑信息和背景是否意外争夺视觉权重；
7. 光线、材料和成像痕迹是否存在合理因果关系；曝光优先级及允许高光 clipping 或暗部下降的位置是否符合 Imaging Mode；
8. 所有必须闭合的高显著性决策是否已经闭合；低显著性不确定性是否已抽象；最终规格中是否仍存在无意保留的场景内容 A/B 分支；
9. 每一个主动新增的具体事实是否服务硬约束、主要视觉意图、可见性、因果、材质可信度或高风险失败控制；是否把未知身份属性、场景类别或近似数量擅自具体化，或仅因为“可以描述”而增加地点、剧情、物件、材料或光源；
10. 当前最可能造成实质偏差的结构关系或审美漂移，是否已经通过足够明确的正向规格和必要的针对性消歧得到控制，同时没有为了防止一种漂移而引入新的未经用户要求的属性。

任一项不成立时先修正规格；只有无法在现有硬约束内解决时才请求用户决定。

## 输出

默认交付连贯的自然语言视觉规格；用户要求结构化、教学或解释时再展示拆解。只写提示词时直接交付最终 Prompt；生成或编辑图像时以同一规格执行。

## 结果检视与定向修订

仅在当前任务实际生成或编辑图像、且结果可见时使用：

- **Critical**：身份、数量、产品或建筑结构、Locked、核心动作等硬约束错误；必须修正。
- **Major**：摄影机、Blocking、接触、视觉中心或光线因果明显偏离，实质削弱主要意图；通常修正。
- **Minor**：不影响识别、叙事和硬约束的轻微背景、色温或装饰差异；通常保留。

修订指令同时写明“修正什么”和“保持什么”，只处理 Critical 与确实影响目标的 Major，不为 Minor 偏差重新生成整个画面。默认最多进行一次自主定向修订；仍有实质偏差时交付当前最佳结果并说明。

## 边界

- 不把任何示例中的性别、族裔、年龄、体型、性感化、品牌、武器、画幅或摄影媒介变成默认值。
- 产品和食物请求按单张商业摄影处理，不扩展为平台规范、商品图集、投放、点击率或转化率工作流。
