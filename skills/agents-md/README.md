# agents-md

项目工程判断提炼与指令维护。根据真实仓库、有效政策与失败经验，创建、审查、重构或更新 AGENTS.md / CLAUDE.md。

它不提供一个让所有项目填满的 AGENTS.md 模板，而是帮助判断：哪些知识会改变 Agent 的选择、依据是什么、应该放在哪一层、怎样判断仍然有效。默认中文；保留命令、路径、标识符和必要技术字段原文。

## 安装到 Codex

解压后，将整个 `agents-md/` 文件夹放在以下位置之一：

```text
~/.agents/skills/agents-md/          用户级：跨仓库使用
<目标仓库>/.agents/skills/agents-md/  仓库级：仅项目使用
```

确认实际路径是 `agents-md/SKILL.md`，不是重复嵌套两层同名目录。更新已有版本前先查看差异；不要直接覆盖自己修改过的文件。一般选择一种安装范围，避免同名副本造成来源混淆。

上述位置与显式调用方式依据 [Codex 官方技能文档](https://learn.chatgpt.com/docs/build-skills)，本次核对日期为 2026-09-30。文件已交付，不代表已经安装到你的电脑。安装后在宿主技能选择器中确认可见；未出现时重新打开会话或重启宿主再核对。其他客户端按其自身技能安装和调用机制配置，不能假定名称相同就有相同加载行为。

## 使用示例

创建或重构：

```text
$agents-md
为当前仓库创建或修订 AGENTS.md。先调查关键工作路径、产品完成条件、
真实工程取舍和容易误判的约束，再落地文件。不要套通用模板，
不要改写用户级规范或已有多 Agent 编排政策。
```

只读审查：

```text
$agents-md
只审查当前仓库的 AGENTS.md / CLAUDE.md，不修改文件。
重点判断哪些规则能指导关键决策，哪些缺乏依据，哪些可能过时或作用域错误。
```

沉淀已知经验：

```text
$agents-md
根据本次已确认的故障原因和相关实现，更新适用范围内的 Agent 指令。
先判断经验是否持久，以及修复是否更适合测试或工具；允许最终不新增规则。
```

普通编码只是需要读取并遵守 AGENTS.md 时，不应额外启动本 SKILL。`agents/openai.yaml` 允许宿主按描述选择，但描述限定了指令维护类任务；隐式触发是否符合预期仍应在实际宿主检查。

## 文件结构

```text
agents-md/
├── SKILL.md                         触发边界与核心工作流程
├── agents/openai.yaml               Codex 展示与调用元数据
├── references/
│   ├── discovery.md                 工程知识发现
│   ├── rule-design.md               规则提炼、强度与例外
│   ├── validation.md                静态、执行、加载及行为验证
│   └── patterns.md                  七个真实样本的可迁移机制
├── scripts/inspect_instructions.py  可选只读盘点器
├── tests/                           工具与包结构的自动化测试
├── evals/                           合成场景与行为评估方法
└── research/                        研究分析、来源与验证记录
```

日常运行不必读取 `research/` 或所有参考材料。包内不包含自动安装钩子、后台任务、外部 API 调用、凭据或模型配置；不会重定义现有主 Agent / subagent 分工。

## 可选只读工具

SKILL 本体不依赖 Python。可选脚本与测试使用 Python 3.10 及以上版本，仅依赖标准库。

将以下路径替换为实际位置：

```sh
python3 /实际安装路径/agents-md/scripts/inspect_instructions.py \
  --root /明确授权的目标仓库
```

脚本输出 JSON，包含候选指令、显式链接是否存在、完全相同正文组、大小、被排除目录及扫描限制。它不读取被引用文档的正文，不跟随目录链接，不读取越界或识别出的敏感目标，不执行任何仓库命令，也不访问网络。

同内容组可能是有效的符号链接，不自动视为问题；普通链接存在不代表标题锚点存在、命令可执行或宿主已加载。部分示例、模板也有同名文件，需要人工判定角色。它不是秘密扫描器，不保证识别所有敏感文件，也不能替代抵御并发恶意文件替换的操作系统沙箱。

默认单文件最多读取 262144 字节，最多遍历 20000 个目录条目；这些是工具资源上限，不是 AGENTS.md 格式标准。可用 `--max-bytes`、`--max-entries` 调整，或重复使用 `--exclude-dir` 追加排除目录。不解析 `.gitignore`；若结果提示截断，不能宣称完整盘点。

返回码 `0` 表示盘点完成并产出结果，可能仍含缺失引用、未读取文件或扫描截断；它不是“质量通过”。参数或根目录错误返回 `2`。

## 检查本包

在技能目录下运行：

```sh
python3 -B -m unittest discover -s tests -v
```

自动化测试验证只读盘点器及本包结构；[16 个场景](evals/README.md) 用于后续真实 Agent 评估。测试状态与限制见 [验证记录](research/validation-report.md)。不能把脚本测试通过当成已经证明 AGENTS.md 产出改善了开发结果。

## 研究基础

本包基于用户提供的《AGENTS.md 工程最佳实践研究报告》和七个指定仓库的只读研究。[完整分析](research/repository-analysis.md) 区分来源观察与设计判断；[来源记录](research/sources.json) 保存提交锚点和读取范围。

内容为原创中文技能与研究性概述，不附带第三方指令全文。样本中的项目政策、模型推荐、权限和审批条件不会自动成为使用本 SKILL 时的默认政策。
