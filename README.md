# MC-SKILLS

MC-SKILLS is the source and distribution home for MC-developed Agent Skills and Agent Plugins.

Other standalone repositories: [Repo-to-Spec-Plugin](https://github.com/MC0571/Repo-to-Spec-Plugin) · [Vison-Harness](https://github.com/MC0571/Vison-Harness)

[中文版](./README.zh-CN.md)

## Standalone Skills

Standalone skills live under `skills/<skill-name>/` and are independently installable.

Skill releases to [Tencent SkillHub](https://skillhub.cn/) and [ClawHub](https://clawhub.ai/) run through [`.github/workflows/skill-release.yml`](./.github/workflows/skill-release.yml). See the [release guide](./skills/skill-release/references/github-actions.md) for its triggers, required Actions variables and secrets, and retry inputs.

## Agent Plugins

Plugin-internal skills stay within their plugin and are distributed through that plugin rather than as standalone entries in the `npx skills` catalog.

<!-- PLUGINS_START -->
<!-- generated by scripts/render-plugin-directory.py; do not edit manually -->

| Plugin | Harness | Category | Version | Description |
|---|---|---|---:|---|
| [code-atlas](./plugins/code-atlas/README.md) | Codex, Claude Code | Developer Tools | 0.3.2 | Read-only analysis workflows; SessionStart maintains the current worktree's .codegraph index and required .gitignore. |
<!-- PLUGINS_END -->

CodeAtlas keeps source analysis read-only while its lifecycle hook maintains the
external CodeGraph runtime for the exact current worktree. On SessionStart it
automatically runs `codegraph init <worktree-root>` when the local database is
missing, or `codegraph sync --quiet <worktree-root>` when it exists. The bounded
attempt only writes the worktree `.codegraph` (and an init-required `.gitignore`),
disables downloads, update checks, telemetry, daemon and watcher behavior, and
never installs Git hooks or configures MCP. A failure becomes `needs-agent` with
an exact same-session takeover command; SubagentStart only observes the result.

## Install

### Standalone Skills

List available skills:

```bash
npx skills add https://github.com/MC0571/MC-SKILLS/tree/main/skills --full-depth --list
```

Install one skill:

```bash
npx skills add https://github.com/MC0571/MC-SKILLS/tree/main/skills --full-depth --skill '<skill-name>'
```

Install all standalone skills for one supported agent:

```bash
npx skills add https://github.com/MC0571/MC-SKILLS/tree/main/skills --full-depth --skill '*' --agent codex
```

For Claude Code, use `--agent claude-code`.

### Agent Plugins

Codex:

```bash
codex plugin marketplace add MC0571/MC-SKILLS
codex plugin add code-atlas@mc-skills
codex plugin list
```

Claude Code:

```bash
claude plugin marketplace add MC0571/MC-SKILLS
claude plugin install code-atlas@mc-skills
claude plugin list
```

Other harnesses are supported only when the artifact explicitly declares and verifies an installation path.

## Maintenance

Regenerate the directory tables after changing skill or plugin metadata:

```bash
python3 scripts/render-plugin-directory.py
```

Run the same repository contract entry point used by CI before opening a pull request:

```bash
python3 scripts/validate-repository.py --base-ref origin/main
python3 scripts/validate-repository.py --self-test
```
